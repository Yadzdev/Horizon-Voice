# Security policy

Horizon Voice is a preview project. Do not send credentials, access tokens, private keys, player IP addresses, or private audio data in GitHub issues.

For a security report, use GitHub's private vulnerability reporting for this repository if enabled. Include only the affected version, minimal reproduction, impact, and a contact method. Do not publish an unpatched exploit in a public issue.

See [docs/SECURITY.md](docs/SECURITY.md) for the current security model, known gaps, and release blockers.
